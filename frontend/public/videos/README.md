# Reference videos

Put one AUTSL clip per sign here, named after its class id:

    0.mp4   abla
    5.mp4   agac
    225.mp4 zor

The Teacher page looks for `/videos/<class id>.mp4`. When a file is missing it
shows "the video for this sign has not been added yet" instead, so the page
works with as few or as many clips as you have.
